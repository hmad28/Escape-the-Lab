# Escape-the-Lab

Game survival horror asimetris untuk Roblox di PC dan mobile. Para Scientist mencari keycard yang membuka gerbang evakuasi sebelum Subject Zero menangkap mereka. Scientist yang tertangkap bisa diselamatkan dari Infection Tube atau berubah menjadi Mini-Mutant dan ikut memburu tim lamanya.

| Pemain | Mode |
|---|---|
| 1–4 | Menunggu ronde. Latihan opsional tersedia untuk 1–2 peserta. |
| 5–6 | Ronde utama, 1 Subject Zero melawan 4–5 Scientist. |

**Status** · Pre-production. Milestone pertama adalah vertical slice satu zona untuk menguji latihan, capture, rescue, mutasi, dan evakuasi dalam latihan 1–2 peserta dan ronde 5–6 pemain.
