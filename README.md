# Escape-the-Lab

Game survival horror asimetris untuk Roblox di PC dan mobile. Para Scientist mencari keycard, menyalakan genset, dan membuka gerbang evakuasi sebelum Subject Zero menangkap mereka. Scientist yang tertangkap bisa diselamatkan dari Infection Tube atau berubah menjadi Mini-Mutant dan ikut memburu tim lamanya.

| Pemain | Mode |
|---|---|
| 1 | Latihan solo untuk mempelajari alur keycard, genset, dan evakuasi. |
| 2 | Latihan co-op dengan skenario rescue. |
| 3 | Ronde pendek, 1 Subject Zero melawan 2 Scientist di satu zona. |
| 4–7 | Ronde utama di tiga zona, hingga 1 Subject Zero melawan 6 Scientist. |

**Status** · Pre-production. Milestone pertama adalah vertical slice satu zona untuk menguji latihan, capture, rescue, mutasi, dan evakuasi dengan 1–4 pemain.
