# Escape the Lab · Referensi 360° Aset M1

Delapan lembar konsep dibuat dengan ImageGen bawaan untuk membantu modeler membuat blockout. Kit modular menampilkan komponennya per baris atau area. Setiap lembar memperlihatkan empat arah, dengan tampak permukaan atau state tambahan pada aset yang memerlukannya.

Pakai [Brief Produksi Aset M1](../../M1_ASSET_BRIEFS.md) sebagai sumber ukuran, pivot, dan bagian mesh. Gambar menunjukkan bentuk dan material. Contoh gate memperlihatkan shutter membuka. Siapkan sendiri ruang gerak shutter di model akhir sesuai clearance di brief. Untuk sudut dinding, pakai denah L dan ukuran grid dari brief. Proporsi piksel bisa berbeda antartampak.
